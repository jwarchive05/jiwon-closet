# 지원의 옷장 (오프라인판)

내 옷, 무신사 좋아요·장바구니, 코디를 사진 위주로 보는 개인 패션 사이트입니다.
**데이터는 엑셀 1개 + 사진 폴더**로 관리하고, `index.html`은 그걸 읽어서 보여주기만 합니다.

## 폴더 구조

```
지원의옷장/
├── 옷장데이터.xlsx    ← 원본 데이터 (여기만 고치면 됨)
├── images/           ← 사진 (엑셀 "사진" 칸의 파일 이름과 같게)
├── index.html        ← 사이트 (더블클릭으로 열기)
├── data.js           ← 처음 열 때 쓰는 기본 스냅샷 (엑셀을 base64로 넣어둔 것)
├── lib/xlsx.full.min.js  ← 엑셀 읽기 도구 (SheetJS, Apache-2.0)
└── README.md
```

## 사용법

1. `index.html` 더블클릭 → 브라우저에서 열림
2. 옷장 등록 작업에서 엑셀과 `data.js`를 함께 갱신하면 새로고침만으로 반영돼요.
   - 엑셀을 직접 편집했다면 **홈 → "엑셀 불러오기"**에서 파일을 선택하거나 끌어다 놓으세요. 브라우저는 다음 기본 데이터 갱신 전까지 불러온 내용을 기억해요.
   - 웹서버에서 열면 최신 엑셀을 자동으로 읽어요.

## 엑셀 시트 규칙 (GPT / 사람 공통)

상품을 찾으면 품번과 색상을 대조한 뒤 `링크`에 브랜드 공식 상품 페이지를 기록한다. 공식 상품 갤러리에서 옷 전체가 보이는 사진을 확인하고, 원본 이미지 파일 그대로 내려받아 `images/`에 넣는다. `사진`에 파일명을 적고 `data.js`도 갱신한다.

### `옷장` — 한 줄 = 옷 한 벌
| 칸 | 내용 | 예시 |
|---|---|---|
| ID | 겹치지 않는 영문 ID. `쇼핑몰-상품번호` 권장 | `uq-471809`, `mo-021`, `kream-130893591` |
| 이름 | 상품명 | 스웨트와이드팬츠 (Uniqlo : C) |
| 브랜드 | | UNIQLO |
| 대분류 | **아우터 / 상의 / 바지 / 신발 / 가방 / 소품 / 속옷/홈웨어** 중 하나 | 바지 |
| 소분류 | 무신사 분류 이름 권장 (코디 팁이 붙음) | 트레이닝/조거 팬츠, 니트/스웨터, 데님 팬츠, 겨울 싱글 코트 … |
| 색 / 소재 / 계절 | 자유 | 03 그레이 / 스웨트 / 가을/겨울 |
| 사이즈 | | L, 30, W30 L32, 270 |
| 실결제가 | **실제로 낸 돈** (숫자만). 모르면 비움 | 49900 |
| 정가 | 참고용 | 49900 |
| 구매일 | YYYY-MM-DD | 2026-11-20 |
| 구매처 | | 유니클로, 무신사, KREAM |
| 링크 | 상품 페이지 URL | https://… |
| 사진 | `images/` 안의 파일 이름. 여러 장이면 한 줄에 하나씩 쓰고, 첫 사진은 카드에 표시 | uq_471809_0.jpg |
| 메모 | 자유 | 태그 품번 486125 |

### `좋아요·장바구니` — 무신사 상품
- `좋아요`: Y/N · `좋아요순위`: 숫자(작을수록 최근)
- **장바구니 상품** = `장바구니옵션` 칸이 채워진 행 (예: `브라운 · L(100)`), `장바구니수량`, `담은날`, `세일종료`
- `할인율`: 0.55 또는 55 둘 다 됨 · `특징`: `핏:루즈 | 두께:보통` 처럼 `|`로 구분
- `사진`: 쉼표로 여러 장 (`5311114_0.jpg, 5311114_1.jpg`) — 두 번째 사진은 카드에 마우스 올리면 보임
- `구매함`: Y면 "옷장에 있어요" 표시 · `판정`: `buy: 이유` / `hold: 이유` / `skip: 이유`
- `가격기록`: `2026-11-23=36540; 2026-12-01=32000` → 가격 인하 표시·그래프

### `코디`
- `아이템`: `c:옷장ID` 또는 `p:상품ID`를 쉼표로 (예: `c:uq-471809, p:musinsa-7129201`)
- 사진은 앞 4개가 코디 카드에 크게 나옴
